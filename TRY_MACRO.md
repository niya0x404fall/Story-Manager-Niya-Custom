# Проба памяти через пресет — beta 0.4.19

Это отдельная тестовая копия beta 0.4.18 с новым режимом саммари.
В GitHub эта сборка не опубликована. Обычное обновление расширения с GitHub
может заменить её версией из выбранной ветки.

## Установить файлы

Если используете этот ZIP вручную, скопируйте содержимое папки
`Story-Manager-Niya-Custom` поверх файлов уже установленной **беты**,
с заменой одноимённых файлов. Нужная папка — та, где лежит её `manifest.json`.
Не создавайте рядом вторую включённую копию Story Manager.
Перезапустите SillyTavern и перезагрузите страницу.

## Подключить память

1. Откройте Prompt Manager своего пресета (Chat Completion).
2. Создайте блок `Story Manager Memory`. Роль: `System`. Позиция: `Relative`.
3. В содержимое вставьте:

   ```text
   {{story_manager_summary}}
   ```

4. Добавьте блок в порядок промптов пресета, включите его и поставьте прямо перед `Chat History`. Сохраните пресет.
5. В Story Manager включите «Использовать саммари в контексте» и выберите место вставки «Через макрос в пресете».

**Без включённого блока в пресете новый режим не отправляет саммари.**
Если пресеты меняются, блок нужен в каждом используемом пресете.
Сам текст памяти подставляется из текущего чата автоматически.

## Проверить результат

В чате с готовым включённым саммари получите один ответ и откройте просмотр
собранного промпта / Prompt Itemization. В запросе должны быть:

- Текст саммари один раз в заданном месте перед перепиской.
- Заголовок `### Story Summary` и содержимое включённых актуальных карточек.
- Подставленный текст вместо буквального `{{story_manager_summary}}`.

Переключите чат: память должна стать памятью нового чата.
В чате без саммари блок будет пустым.

## Вернуться к прежнему способу

Выберите прежнее место вставки, например `Main Prompt`.
Макрос станет пустым, а обычная вставка памяти восстановится.
Блок пресета можно оставить включённым.

Создание, сжатие и хранение карточек работают по прежней логике.
Проверки этой сборки описаны в `VALIDATION_0.4.19.md`.
