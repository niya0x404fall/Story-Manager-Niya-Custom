# Story Manager

Расширение для [SillyTavern](https://sillytavern.app/), которое помогает **собирать и хранить сюжет** из переписки: заметки, персонажей, локации и краткий пересказ (саммари).

Подходит для длинных ролевых историй, где важно не потерять детали сюжета.

---

## Что умеет

- **Заметки** — короткие записи о важных событиях из сообщений чата.
- **Персонажи** — карточки NPC с описанием персонажа и ключевыми словами для лорбука.
- **Локации** — карточки мест с атмосферой, особенностями и «ощущениями» локации.
- **Саммари** — хронологический пересказ истории по частям; можно выбрать точный диапазон, выборочно сжать карточки, пересобрать всё или заполнить пробелы.
- **Резервная копия** — JSON-экспорт и импорт данных Story Manager для текущего чата.
- **Экспорт в лорбук** — персонажей и локации можно отправить в выбранный лорбук.

---

## Установка

1. Открой SillyTavern → **Extensions** (расширения).
2. Нажми **Install extension** (установить расширение).
3. Вставь ссылку на репозиторий:
  ```
   https://github.com/SaraSardis/Story-Manager
  ```
4. Дождись установки и перезагрузи страницу при необходимости.

**Обновление:** Extensions → **Manage extensions** → найди Story Manager → **Update**.

## Кнопки на сообщениях

На каждом сообщении в чате появляются иконки Story Manager:


| Кнопка | Что делает                                                                                 |
| ------ | ------------------------------------------------------------------------------------------ |
| 📌     | Создать **заметку** из этого сообщения                                                     |
| 👤     | Создать **карточку персонажа** (берёт контекст из соседних сообщений)                      |
| 📍     | Создать **карточку локации** (берёт контекст из соседних сообщений)                        |
| 📖     | Индикатор **саммари** — сколько сообщений осталось до следующего автоматического пересказа |


Созданные элементы появляются в панели Story Manager. Их можно включать и выключать — в промпт попадают только **включённые и актуальные** карточки.

---

## Профиль для генерации

Story Manager может делать фоновые запросы к модели **через отдельный connection profile**, не переключая ваш основной профиль в чате.

- **«Использовать текущий профиль»** — генерация идёт с теми же настройками, что и обычный чат.
- **Выбранный профиль** — заметки, карточки и саммари создаются через указанный профиль.

---

## Заметки, персонажи и локации

**Заметки** — короткий заголовок и текст. Можно создать вручную или сгенерировать из сообщения.

**Персонажи и локации** — структурированные карточки для лорбука:

- имя и ключевые слова (для срабатывания в лорбуке);
- описание места/персонажа

Для персонажей и локаций можно выбрать, **какие сообщения брать в контекст**:

- *более старые* — история до выбранного сообщения;
- *более новые* — история после него.

Отсчет ведется от того сообщения, на котором вы нажали нужную кнопку.

Карточку можно **экспортировать в лорбук**, выбранный в общих настройках.

---

## Саммари (пересказ)

Саммари хранится **кусками** (карточками). Каждый кусок — пересказ определённого диапазона истории. Цифры в названии — исходные `mesid` сообщений.

Настройки разделены:

- **Использовать саммари в контексте** — отправлять актуальные включённые карточки основной модели.
- **Создавать саммари автоматически** — добавлять новую карточку после накопления N новых видимых сообщений.

Автоматика запускается только с очередным видимым сообщением пользователя. Этот новый ход не входит в карточку: Story Manager пересказывает принятую историю перед ним, включая все ответы персонажей в групповом чате. Так остаётся время скрыть неудачный ответ или выбрать другой свайп до запуска запроса.

Скрытые сообщения не приближают порог периодичности. Уже обработанные диапазоны и сохранённые источники не пересказываются следующей автоматической карточкой. Если ранее исключённое сообщение открыть внутри старого диапазона, оно появляется как отдельный пробел, а не примешивается в новую историю из конца чата.

Скрытые сообщения не отправляются генератору **нового** саммари. Если скрыть или снова открыть сообщение уже после создания карточки, готовое саммари остаётся активным: hide/unhide управляет передачей сырой истории, а не каноном. Карточка становится красной только после правки текста, смены свайпа или удаления исходного сообщения; до исправления она исключается из контекста и считается пробелом.

Начиная с 0.4.4 новые карточки запоминают точный набор отправленных сообщений. Правка исключённой скрытой ветки не делает такую карточку устаревшей. Если открыть ранее исключённое сообщение, карточка остаётся активной; при следующем отображении списка появляется жёлтая подсказка, а сообщение доступно в «Заполнить пробелы».

**Круговая стрелка** сначала открывает выбор. «По сохранённым исходникам» использует тот же набор сообщений в их текущей редакции, включая скрытые позже. «Только видимые сейчас» заново выбирает сообщения в диапазоне. У старых карточек точный состав неизвестен: доступны «Только видимые сейчас» и явное «Весь диапазон, включая скрытые». Отмена ничего не отправляет; выбор варианта запускает один запрос. У сжатой карточки стрелочка повторно сокращает сохранённый текст.

**Карандаш → Сохранить** работает локально, даже без изменения текста. Он подтверждает правильность карточки и не добавляет новые сообщения в сохранённый набор источников. Старую карточку это не превращает в карточку с известным происхождением.

**Дата и время** берутся из текста ролевой: повествования, статусов, HTML и пользовательских тегов. Промпт позволяет продолжать дату предыдущего саммари и учитывать явное «на следующий день». Если известно только время, недостающая дата не выдумывается. Если нет временных сведений, префикс пропускается. Старые тексты карточек автоматически не переписываются. Распознавание выполняет выбранная модель; локальные тесты проверяют передаваемый ей текст и инструкции, а не качество её ответа.

Для проверки сборки используйте `TESTING_0.4.5.md` и тестовую копию чата. Локальные тесты без API: `npm test` (Node с поддержкой VM modules).

Полезные кнопки:

- **Создать по диапазону** — сделать карточку по точным включительным границам `mesid`; при пересечении с существующей карточкой появится предупреждение.
- **Сократить саммари** — сжать только карточки, отмеченные второй галочкой.
- **Сделать саммари с нуля** — пересобрать пересказ по всей истории чата.
- **Подтянуть из Саммари** — импорт текста из встроенного Summarize SillyTavern.
- **Заполнить пробелы** — создать куски для участков истории, которые ещё не попали в пересказ.
- **Отменить сокращение** — вернуть карточки до последнего сжатия (если доступно).

Саммари можно вставить в Main Prompt, перед Main Prompt или в историю на выбранной глубине. `Depth 0` означает позицию после истории. Заметки, персонажи и локации пока остаются в Main Prompt.

## Где хранятся данные

- **Общие настройки** (промпты и профиль) — в настройках расширения SillyTavern.
- **Заметки, персонажи, локации и саммари** — **отдельно для каждого чата**, в метаданных чата.

В Niya Custom 0.4.5 внешние картинки отключены. Старые настройки, пресеты и данные картинок не удаляются из хранилища и резервных копий, но интерфейс и автогенерация картинок не запускаются.

При смене чата списки в панели обновляются автоматически.

Кнопки **Экспорт данных** и **Импорт данных** создают переносимую резервную копию Story Manager. Локальный connection profile и выбранный лорбук не переносятся между установками.

## Требования

- SillyTavern с поддержкой UI-расширений.
- Для генерации заметок, карточек и саммари — настроенный API (connection profile или текущий профиль чата).

## Структура проекта (для разработчиков)

```
index.js              — точка входа
bootstrap.js          — инициализация расширения
modules/              — логика: сущности, генераторы, UI, профили API
templates/            — HTML-шаблоны панели и кнопок
style.css             — стили
```

Сборка не нужна — расширение работает как обычные ES-модули в браузере.
