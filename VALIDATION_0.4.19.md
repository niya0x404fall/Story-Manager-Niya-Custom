# Проверки beta 0.4.19

Основа — приложенный архив beta 0.4.18. Стабильная main 0.4.12 не изменена.

## Выполнено

- Исходная beta: `npm test` — 67/67.
- Изменённая сборка: `npm test` — 76/76.
- Синтаксис изменённых JS-модулей и нового браузерного сценария: `node --check`.
- Сверка формата регистрации с официальной документацией SillyTavern и исходниками ветки `release` (`macros.js`, `macro-system.js`, `st-context.js`).

Новые функциональные проверки используют реальные модули Story Manager и локальные заглушки API SillyTavern. Покрыты:

- Переход обычная вставка → макрос → Depth: очистка старой вставки и пустой макрос в обычном режиме.
- Актуальность после правки текста и смены чата; пустая память без карточек/метаданных.
- Одинаковые сортировка, формат и исключение отключённых, устаревших, пустых, недоступных карточек и placeholder.
- Отключение саммари; сохранение отдельной вставки заметок, NPC и локаций.
- Синхронная однократная регистрация через совместимый API и обе формы нового API.
- Сохранённый режим при недоступном API: обычная вставка в Main Prompt.
- Сохранение нового значения настройки и прежний дефолт Main Prompt.

## Ограничения

Браузерный сценарий `tests/summary-macro.browser.mjs` подготовлен, но не выполнен:
в среде нет рабочего Chromium, загрузка Playwright Chromium получила HTTP 403.
Расположение элементов на экране не проверено визуально.

В работающей SillyTavern и с реальным пресетом сборка ещё не проверена.
Нужно проверить подстановку в итоговом запросе, положение относительно Chat History,
единственный экземпляр памяти и смену чата по инструкции `TRY_MACRO.md`.

Для браузерного сценария нужны Playwright и файл jQuery из SillyTavern:

```sh
ST_REFERENCE_ROOT=/path/to/SillyTavern node tests/summary-macro.browser.mjs
```

При системном Chromium задайте `ST_CHROMIUM_EXECUTABLE=/path/to/chromium`.
